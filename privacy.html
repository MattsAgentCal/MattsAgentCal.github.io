Privacy policy

Matt Traces Archive is a personal-use desktop backup tool. The owner is its only user.

Access and purpose

The app backs up the owner's own agent trace files to the owner's own Google Drive. It uses Google's drive.file permission and only accesses files it creates. It does not read unrelated files in Drive or request access to the entire Drive.

Use and storage

Trace contents, file names and related backup metadata are used only to create and maintain those personal backups. Source files remain in the owner's local backup setup. Cloud copies are stored in the owner's Google Drive, not on this website.

Google authorization credentials are used by the owner's local backup setup. This website does not receive or store those credentials or trace files.

No sharing

The app does not sell, publish, or share trace files or Google user data with third parties. Its only cloud destination is the owner's own Google Drive. Data is not used for advertising or AI model training.

This information site has no analytics, advertising, forms, or third-party scripts. GitHub Pages hosts it and may process ordinary web request information under GitHub's own privacy practices.

Retention and deletion

Backups remain in the owner's Drive until the owner deletes them or removes them through the backup setup. The owner can delete the app-created files in Google Drive and empty the trash to remove them permanently. Local source files are managed separately by the owner.

Revoke access

Open Google Account connections, select Matt Traces Archive, and use Google's option to remove its access or delete the connection. Confirm the removal.

Revoking access prevents future authorized backups. It does not automatically delete existing backups; delete those separately in Google Drive. Reconnecting the app later requires the owner's authorization again.
