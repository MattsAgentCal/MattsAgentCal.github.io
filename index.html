Personal trace backups

Matt Traces Archive is a personal-use desktop tool. It backs up the owner's own agent trace files to the owner's own Google Drive.

Private by purpose

The owner is the only user. Google Drive access uses the drive.file scope and is limited to files this app creates. It does not access unrelated Drive files.

This website provides information only. It does not sign users in, upload files, or receive Google credentials.
